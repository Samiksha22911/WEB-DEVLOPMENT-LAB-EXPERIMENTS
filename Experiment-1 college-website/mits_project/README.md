# Responsive Multi-Section College Website

## Files

* `index.html` — Complete page structure
* `style.css` — Responsive styling
* `script.js` — Dropdown click interaction
* `images/mits-logo.png` — Local college logo

## How to Run

No installation is required.

Simply open `index.html` in any modern web browser.

## Note

The supplied lab PDF describes **Experiment 1 as a Responsive Multi-Section College Website**, not an e-commerce website.

This implementation follows the **Experiment 1 expected-output screenshots** and recreates the visible structure using plain **HTML, CSS and JavaScript**.
